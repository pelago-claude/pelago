Try it

Without your data, and without downloading anything if you prefer.

  • In the browser

    The real program in a web page, with the example account: invented data, no requests to the internet and, once you close the page, nothing is left behind.

    Open the demo

    The first time it downloads about 12 MB, then it stays in the browser's memory. It is designed for a computer. Some features are off: opening files, exporting, updating prices.

  • On your PC

    Download Pelago, start it without opening any file and press “Try an example account”: a second window opens with an invented account, in a temporary folder that disappears when you close it.

    Download for Windows

  • With the example CSV

    Download the invented CSV and open it in the program with “Open CSV…”.

    Download the example CSV

Five things to try

  1. Portfolio map → “Play”: watch holdings appear, grow and disappear.
  2. Move the slider to a day in the past: the map and Composition on a date show the account as it was.
  3. Turn on Assistant mode (bottom left) and hover a column or a number.
  4. Change the language and the theme, also bottom left.
  5. Open the Tax summary: these are informational estimates, and the program reminds you with a notice.

The demo is not the program: it saves nothing and reads none of your files. To use your own data you need the program, which runs on your PC. Why a program and not a website.
